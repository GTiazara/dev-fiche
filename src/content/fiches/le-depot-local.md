## Définition

`git init` crée un dépôt dans un dossier. Les fichiers suivis pourront ensuite être enregistrés dans l'historique.

## Mots-clés

| Commande | Rôle |
| --- | --- |
| git init | Crée le dépôt |
| git status | Montre l'état des fichiers |

## Exemple de code

```bash
git init
git status
```

## À retenir

Le dépôt local existe avant toute publication. `git status` ne modifie pas les fichiers.
