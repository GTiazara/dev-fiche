## Définition

Un objet relie un nom de propriété à une valeur. On lit une propriété avec le point.

## Mots-clés

| Notion | Rôle |
| --- | --- |
| propriété | Nom d'une valeur dans l'objet |
| méthode | Fonction rangée dans l'objet |

## Exemple de code

```js
const livre = { titre: "Fiches", pages: 12 };
console.log(livre.titre);
```

## À retenir

Les accolades créent l'objet. Chaque propriété a un nom unique dans cet objet.
